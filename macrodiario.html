Para guardar tus datos en la nube y exigir inicio de sesión con Google: 1) crea un proyecto en console.firebase.google.com; 2) en Authentication activa el método Google; 3) crea una base de datos Firestore; 4) añade una app web y copia su firebaseConfig; 5) pégalo aquí.

Se sincronizan objetivos, comidas, favoritos, comidas creadas, raciones propias y chats. La API key de Gemini y el proxy se quedan solo en este dispositivo.

Solo se necesita para identificar alimentos a partir de una foto del plato. Se guarda únicamente en este navegador y se envía directamente a Google, nunca a otro servidor. Consíguela en aistudio.google.com/apikey.

Solo rellénalo si "Buscar" te da error de conexión. Es la URL de un pequeño Cloudflare Worker propio que reenvía la búsqueda a Open Food Facts añadiendo cabeceras CORS. Déjalo vacío para llamar directamente.
